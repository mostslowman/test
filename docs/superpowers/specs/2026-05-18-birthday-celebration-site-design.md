# 生日庆祝沉浸式网站 — 设计文档

## 1. 项目概述

一个沉浸式的生日庆祝网站，提供被庆祝的沉浸式体验。包含后端管理配置和前端三个展示页面，支持用户上传图片、音频和文本祝福语。

## 2. 技术栈

- **后端**: Node.js + Express + Multer（文件上传）
- **前端**: 纯 HTML/CSS/JS + Three.js（3D 旋转运镜）
- **存储**: 文件系统存储（uploads/ 目录）
- **端口**: 3000

## 4. 后端 API 设计

| 接口 | 方法 | 功能 | 请求格式 | 响应 |
|------|------|------|----------|------|
| `/api/upload/images` | POST | 上传图片（最多8张） | multipart/form-data, field: `images[]` | `{ success: true, files: [...] }` |
| `/api/upload/audio` | POST | 上传音频 | multipart/form-data, field: `audio` | `{ success: true, file: "..." }` |
| `/api/upload/text` | POST | 上传祝福语 | JSON `{ "text": "..." }` | `{ success: true }` |
| `/api/config` | GET | 获取所有已上传内容 | - | `{ images: [...], audio: "...", text: "..." }` |
| `/api/reset` | POST | 重置所有内容 | - | `{ success: true }` |

### 文件上传限制

- 图片: 最多8张，支持 jpg/png/webp，单张最大 20MB
- 音频: 1个，支持 mp3/wav/ogg，无时间限制，最大 100MB
- 文本: 最多100字，使用楷体显示

## 5. 后台管理页面（/admin）

### 布局
- 顶部标题: "🎂 生日网站配置中心"
- 三个功能区垂直排列
- 底部"生成分享链接"按钮

### 功能区
1. **图片上传区**: 拖拽/点击上传，预览缩略图，显示已上传/上限，可删除
2. **音频上传区**: 上传按钮，上传后可试听播放器
3. **文本编辑区**: textarea 限制100字，楷体，实时字数统计

### 生成链接
- 保存所有配置到 uploads/config.json
- 显示分享链接: `http://host:3000/`

## 6. 前端页面设计

### 6.1 页面1 — 生日信封展示页（index.html）

#### 视觉设计
- **背景**: Canvas 绘制的卡通风格背景，蛋糕和祝福语（"生日快乐"、"天天开心"）随机分布，柔和渐变色天空
- **中央**: 一个 3D 风格的精致的信封，带有折痕和封口。信封中央有一个跳动的小爱心
- **右下角**: 透明底色的"下一页"按钮，hover 时发光

#### 动画
1. 页面加载: 彩纸从顶部飘落，信封从底部缓缓升入中央
2. 爱心持续跳动（scale 1.0 ↔ 1.15，周期 1s）
3. 背景祝福语缓慢浮动（translateY 随机偏移）
4. 点击"下一页" → fadeOut 过渡到 page2.html

#### 跳转
- 右下角"下一页"按钮 → window.location.href = 'page2.html'

### 6.2 页面2 — 生日祝福语展示页（page2.html）

#### 视觉设计
- **背景**: 信纸周围环绕 6-8 个 AI 生成的卡通人物，面向中央，营造围观氛围
- **中央**: 带有复古纹理的信纸，边缘轻微泛黄效果
- **右下角**: 透明底色的"下一页"按钮，初始隐藏，文字显示完毕后浮现

#### 动画
1. 页面加载: 信纸从上方飘落至中央（ease-out 弹跳）
2. 打字机效果: 文本逐个显现，间隔 0.1s，光标闪烁
3. 卡通人物轻微晃动（每 3s 随机晃动一次）
4. 文本显示完毕后，按钮渐入显示

#### 跳转
- 点击"下一页" → fadeOut 过渡到 page3.html

### 6.3 页面3 — 图片与音频展示页（page3.html）

#### 视觉设计
- **背景**: 用户上传的第一张图片作为背景，半透明遮罩
- **主视觉**: 3D 空间中的多屏幕展示
  - 每个屏幕（平面）显示一张用户上传的图片
  - 屏幕数以用户上传的图片数量为准（1-8个）
  - 屏幕以 3D 旋转排列在空间中

#### 多屏载入特效
- 每个屏幕从不同方向飞入（延迟递增 0.2s）
- 飞入后排列在 3D 空间中的环形轨道上
- 屏幕之间相互错落，形成层次感

#### 旋转运镜特效（Three.js）
- 相机围绕 Y 轴旋转，每次展示一张图片
- 每张图片展示时，相机执行 360° 旋转运镜
- 旋转周期: 每张图片 4 秒
- 切换效果: 当前图片淡出，下一张淡入
- 全部展示完后从第一张重新开始
- 运镜路径: 平滑曲线，带缓动函数

#### 音频控制条（底部）
- 播放/暂停按钮
- 进度条（可拖拽，显示当前时间/总时长）
- 音量滑块（0-100%）
- 播放速度控制（0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x）
- 页面进入时自动开始播放

#### 跳转
- 底部或左上角"返回首页"按钮 → 回到 index.html

## 7. 交互系统设计

### 全局交互
- 所有页面切换使用平滑渐变过渡（fade 0.5s）
- 所有按钮 hover 有效果反馈（发光或放大）
- 页面加载有进入动画

### 独特交互
1. **信封页**: 点击爱心可触发彩纸特效爆发
2. **祝福语页**: 文本显示完毕后，点击信纸可触发飘落花瓣特效
3. **展示页**: 鼠标拖拽可手动控制 3D 旋转视角，与自动运镜无缝切换

## 8. 性能优化

- 图片上传时进行压缩（sharp 库）
- Three.js 使用 BufferGeometry 优化渲染
- 使用 requestAnimationFrame 进行动画循环
- 字体预加载（楷体）
- 音频使用 MediaSession API 进行后台控制

## 9. 素材生成计划

使用 byted-seedream-image-generate 技能生成以下素材：

1. **信封图片** (envelope.png): 可爱的卡通风格生日信封，粉色系，带有封口和装饰
2. **背景图元素**: 蛋糕、礼物等卡通装饰元素
3. **信纸图片** (letter-paper.png): 复古风格的泛黄信纸，带有纹理
4. **卡通人物** (6-8个): 各种风格的可爱卡通人物，面向中央，表情生动
5. **爱心图标** (heart.png): 粉色跳动爱心

- 单服务器部署
